Welcome to KeyRemapper

KeyRemapper needs Hammerspoon to remap keys. Here's how to get set up:

1

Install Hammerspoon

Download it from hammerspoon.org and drag it to your Applications folder.

—
2

Create a config file

KeyRemapper can create the ~/.hammerspoon/init.lua file for you.

—

Troubleshoot

"My remaps don't work or are out of date"

Click the tiny hammer in your menu bar, then hit Reload Config.

"The hammer icon isn't showing"

No hammer? Open the Hammerspoon app to bring it back.
